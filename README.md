# HTML開示だな
### 概要
Claude Codeにハマった友人が スマホでhtmlを起動したいと言うので作ったアプリ。
LINEで手軽に共有できるようにtxtファイルとの互換性も備えている。

### こだわり
アプリのコンセプトは「HTMLファイルの取り扱い方もエディタも知らない」というAIコーディング次世代のために、AIが作ってくれた単一HTMLファイルを実際にWebアプリとして起動できるようなアプリを作ってやろう
ということ。
LINEではまともにhtmlファイルが送れない！とトッモが嘆いていたので、htmlをtxtファイルに変換する機能と、txtファイルへの変換後でもそのまま読み込んでアプリを使用できる仕様にした。
htmlをインポートして開くだけなので基本的に単純なプログラムで構成されている。
友人の依頼により、超ドシンプルなUIになっている。

### 思い出話
一般の人間にはスマホの標準アプリである「ファイル」アプリも馴染みがないだろうなということで、最初はhtmlファイルを画像ファイルに変換して読み込めるんじゃないかと試行錯誤してみたが、LINEの圧縮が甚だしすぎたので断念。QRコードの偉大さを知った。デンソーさぁ～ん。
